# Hindustan Unilever Limited (HUL) — Financial Analysis

## Project Overview
This project presents a financial analysis and valuation model of Hindustan Unilever Limited (HUL), built using Microsoft Excel.

## Financial Analysis Modules
- Financial statement analysis
- Ratio analysis
- Common-size financial statements
- Cash flow analysis
- Financial forecasting
- Discounted Cash Flow (DCF) valuation
- Comparable company valuation
- DuPont analysis
- Altman's Z-Score analysis
- Beta regression

## Tools Used
- Microsoft Excel
- Financial modelling and valuation techniques

## Objective
To analyse the company's financial performance, assess financial risk, and explore valuation methods using historical financial data and forecasting assumptions.

## File
`HUL_Financial_Analysis.xlsx` — Excel workbook containing the financial analysis and valuation models.

## Disclaimer
This project is for educational and portfolio demonstration purposes only. It is not investment advice.
